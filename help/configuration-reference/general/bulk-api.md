|--- |--- |--- |
|[!UICONTROL Maximum Entities Per Bulk Request]|Global|Displays the maximum number of entities that can be processed in a single bulk request. [Bulk APIs](https://developer.adobe.com/commerce/webapi/rest/use-rest/bulk-endpoints/){target="_blank"} are recommended to combine multiple calls into a single request to reduce the number of requests and improve performance. Customers can request an increase to the [!UICONTROL Maximum Entities Per Bulk Request] by contacting [Adobe Commerce Support](https://experienceleague.adobe.com/en/support?support-tab=home#support). Adobe will review your use case and determine if increasing your bulk request size is appropriate.|
