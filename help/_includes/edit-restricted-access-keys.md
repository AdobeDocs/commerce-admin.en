# Edit restricted access keys

Assign or unassign keys from a catalog view, not from the main [!UICONTROL Restricted Access Keys] grid. You can make this change from either the shared catalog's _[!UICONTROL Catalog Views]_ tab or the associated company's _[!UICONTROL Catalog Views]_ section — both list the same catalog views and current key assignments.

A catalog view must have at least one key and can have at most three. If you try to assign a fourth key, the save fails with a message telling you to remove one first.

1. Open the _[!UICONTROL Catalog Views]_ grid for the catalog view you want to update, using one of the following paths:

   - _From the shared catalog_ — On the _Admin_ sidebar, go to **[!UICONTROL Catalog]** > **[!UICONTROL Shared Catalogs]**. For the shared catalog, select **[!UICONTROL General Settings]** from the **[!UICONTROL Action]** column. Then, in the _[!UICONTROL Shared Catalog Information]_ panel, select **[!UICONTROL Catalog Views]**.
   - _From the company_ — On the _Admin_ sidebar, go to **[!UICONTROL Customers]** > **[!UICONTROL Companies]**. For the company, select **[!UICONTROL Edit]** from the **[!UICONTROL Action]** column. Then expand the **[!UICONTROL Catalog Views]** section.

   Both grids list the catalog views created for the shared catalog assigned to the company, including their assigned keys.

1. Select **[!UICONTROL Edit Restricted Access Keys]** for the catalog view you want to update.

   ![Edit Restricted Access Keys picker showing keys assigned to a catalog view](/help/systems/assets/restricted-access-key-selector.png){width="500" zoomable="yes"}

1. In the **[!UICONTROL Access Keys]** field, select an unassigned key by the [!UICONTROL Key ID] value.

   Keys already assigned to a different catalog view are labeled accordingly.

1. Click **[!UICONTROL Done]** to assign the key to the catalog view.

1. Click **[!UICONTROL Save]**.
